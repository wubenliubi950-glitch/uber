# 配達判定（Uber Eats 自転車配達 判定 Web アプリ MVP）

岡山市北区の谷万成周辺で自転車 Uber Eats 配達をする利用者向けの、案件「行く／微妙／行かない」判定を素早く行うための補助 Web アプリです。**配達中の操作を支援するものではなく、必ず安全な場所で停止してから利用する判断補助ツール**です。

Uber API 連携や Uber Driver アプリの自動操作は一切行いません。手入力およびスクリーンショットの OCR 補助で動作します。

## 概要

- 報酬・予想時間・距離・受取店舗名・配達先エリア・時間帯・雨天有無を入力 → スコアリング → 「行く／微妙／行かない」を即判定
- 判定理由・時給換算・¥/km・地図検索リンクを表示
- 履歴を端末内（localStorage）に保存。実際に受けたか・実際にかかった時間も追記可能
- スクリーンショットを OCR して報酬・時間・距離を自動入力（補助機能。失敗時は手入力でフォロー可能）
- 設定で目標時給・NG/注意/おすすめエリア・しきい値を変更可能
- PWA 対応（ホーム画面追加・最小オフラインキャッシュ）

## 技術スタック

- Next.js 14 App Router（TypeScript）
- Tailwind CSS（OSダーク追従）
- tesseract.js（クライアントサイド OCR、動的 import）
- 永続化：localStorage（将来 Supabase 等に置き換えやすいよう `lib/storage.ts` に隔離）

## 使い方

1. ホーム画面で「手入力で判定」または「スクショをアップロード」を選びます
2. 報酬・予想時間・距離・配達先エリアなどを入力（OCR 利用時はその結果を必ず手で確認）
3. 「判定する」を押すと結果画面に遷移します
4. 結果画面で：
   - 「行く／微妙／行かない」と判定理由・注意点を確認
   - Google/Apple Maps 検索リンクで受取・配達先のおおよその位置を確認
   - 「この案件を保存」で履歴に追加
   - 必要に応じて「実績を記録する」（受けたか・実際の時間・メモ）を追記
5. 「履歴」画面で過去の判定一覧を確認・削除できます
6. 「設定」画面で目標時給や NG/注意/おすすめエリア、各種しきい値を編集できます

## 判定ロジックの説明

`lib/scoring.ts` の `calculateDeliveryScore(input, settings)` で算出します。初期スコア 100 から条件に応じて加減点し、0〜100 にクランプします。

| 観点 | 概要 |
| ---- | ---- |
| 時給換算 | 目標時給以上で +10、1,500〜目標で -10、1,200〜1,500 で -20、1,200 未満で -35 |
| 報酬 | 最低ライン未満で -15、800円以上で +5、1,000円以上で +10 |
| 予想時間 | 長時間しきい値以上で -20、30〜長時間で -10、15分以下で +5 |
| 距離 | 長距離しきい値以上で -20、4km〜長距離で -10、2km以下で +5 |
| エリア | NG -35 / 注意 -15 / おすすめ +10（配達先文字列に含まれるかで判定） |
| 坂道リスク | 配達先またはメモに「坂・団地・山・北部・住宅地・丘・半田山・横井上・津高」が含まれると -20 |
| 夜間 × 坂道 | 夜間かつ坂道リスクがあれば追加 -15 |
| 雨の日 | 坂道リスクがあれば -20、なければ目標時給以上で +10 |
| 中心部から離れる | NG/注意エリア かつ 4km 以上で -15 |

判定文言：
- score >= 75 → 「行く」
- 50 <= score < 75 → 「微妙。条件付きで行く」
- score < 50 → 「行かない」
- 例外：NG エリア かつ 時給 < 目標時給 の場合は強制的に「行かない」

判定の理由（reasons）と注意点（cautions）は配列で返り、画面に箇条書き表示されます。

## 初期エリア設定

- **NG**：横井上、津高、半田山、一宮、辛川市場、芳賀、山側住宅団地、坂の多い北部エリア
- **注意**：津島、伊島、三野、原尾島、中井町、高島、西大寺、大元から遠く離れる方面
- **おすすめ**：岡山駅周辺、表町、柳町、田町、中山下、大元、今、問屋町、奉還町、清輝橋、市街地の平地エリア

設定画面から自由に編集できます。

## OCR の限界

- tesseract.js はブラウザ上で動く軽量 OCR で、Uber Driver アプリの完全な解析は保証しません
- 端末性能により処理に数十秒かかる場合があります
- 文字認識は **必ず誤りを含む可能性があります**。OCR 結果は補助情報として表示するだけで、最終的な値は **必ず手で確認・修正してください**
- 画像はメモリ上で処理し、localStorage 等には保存しません（個人情報・詳細住所の保護）
- 認識に失敗した場合はアラート表示のみでアプリは停止しません。引き続き手入力で判定できます

## 安全上の注意

- **走行中にスマホ操作をしないでください。必ず安全な場所で停止してから判定してください**
- 自転車では坂道・大通り・階段・細道に注意してください
- 出発前にルートを確認してください
- 本アプリの判定はあくまで判断補助です。最終的な受注判断と安全確認は利用者自身の責任で行ってください

## 今後の改善案

- 実際の配達結果（受けた / 実時間 / メモ）を蓄積してスコアリングを改善
- エリアごとの実績時給を可視化
- Supabase などへの保存切り替え（`lib/storage.ts` 差し替えで対応可能な設計）
- 天気 API 連携（雨天判定の自動化）
- 地図 API 連携によるルート算出
- 坂道データや標高データを取り込んで坂道リスクを自動推定
- 配達後に中心部へ戻る時間の推定
- 曜日・時間帯ごとの収益分析
- 自分専用の NG エリア自動学習（受けなかった案件の傾向から提案）
